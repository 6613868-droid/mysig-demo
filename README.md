# MYSIG — концепт «Балтийские сумерки»

Концепт-витрина бренда свечей и диффузоров ручной работы (Калининград).
Портфолио-кейс: арт-дирекшн → типографика → палитра → UX → вёрстка → доводка.

## Как посмотреть

- Локально: открыть `index.html` двойным кликом (для шрифтов нужен интернет).
- Или через локальный сервер: `python -m http.server 8734` в этой папке → http://localhost:8734/

Публикация (GitHub Pages) пока не делалась — по договорённости, сначала смотрим.

## Дизайн-система

Палитра:

| Роль | Название | HEX |
|---|---|---|
| Фон | Кость | `#F4EFE7` |
| Карточки | Дюна | `#E6DCCB` |
| Акцент | Янтарь | `#C08A3E` |
| Текст / тёмные секции | Графит | `#262522` |
| Второстепенный текст | Туман | `#97A6A3` |

Шрифты (Google Fonts, оба с кириллицей):

- **Cormorant Garamond** — заголовки, крупные цифры, курсивные акценты
- **Manrope** — текст, интерфейс, подписи-индексы (uppercase, трекинг 0.12em)

Приёмы: нумерация секций (№ 01–06), тонкие хайрлайны, stagger-сетка коллекции,
тёмная секция «Ритуал» для ритма, плёночное зерно поверх страницы,
плавные reveal-анимации (отключаются при prefers-reduced-motion).

## Структура

1. Hero — слоган + dusk-градиент (место под `images/hero.jpg`)
2. Манифест + три факта (94% / 0% / 100%)
3. Коллекция — 4 карточки
4. Ароматы Балтики — 3 позиции
5. Мастерская в Понарте
6. Ритуал — 3 правила ухода (тёмная секция)
7. Заказ — форма (демо: данные никуда не отправляются) + промокод MYSIG

## Файлы

- `index.html` — разметка всех секций
- `style.css` — дизайн-система (переменные палитры в начале файла)
